## 三列根因

### 已证实

- `World::step` 在候选状态上执行；`NumericFault` 丢弃候选，提交边界的规范字节与 `state_hash` 不变，`last_events` 为空，tick 不推进。关闭注入后再走同一步，与从未注入的参考世界一致。
- 档案 `write_snapshot` 在 rename 前失败时不登记 SQLite 行，恢复索引不能指向缺失快照。
- `IntervalFeedback` 的光合 extent / N+O 摄取 / ΔE 已写入；感官 26–31 不再在 `ticks>0` 时报告“测得零”。这会改变生命输入，因此 C5 必须新 `experiment_hash`。
- 诊断 P 与分类账本（维持、偿债、认知、推进、转向、代谢 E_new、光合 extent）为只读侧信道；开关探针不改变 `state_hash`。
- 动作费用专项与 P3 缩放符合账本：静止 0、直行 100000、转向 20000、混合 120000、撞墙仍付推进费；旧 E 不足时不能用 `e_new` 补差。
- C0：灯心静止 20000 ticks 存活，且实际光合非零，基础资源闭环可以支付生命费用（允许容量满时净 P 不增）。
- 原 E0 的跨零结论仍然成立：后半程代谢 E 差值区间跨零；该指标也可来自旧 C。

### 被证据削弱

- “同化完全不工作，所以 10000 ticks 前必然死亡”被 C0 削弱：在灯心且不运动时，外来同化可以覆盖基础费用。
- 因此换灯前死亡更宜解释为**没能持续待在补给区**（或运动把费用打高），而不是灯下物理闭环不存在。
- “推进/转向扣费实现数量级错误”被分项账本削弱（100 ticks 专项与规则 1000/200 μE 一致）。

### 未知

- 完整 64 维特征 + 在线 actor–critic 在反转图上是否产生可靠适应：C5 复现仍不得改写为通过。
- 奖励时间尺度（γ≈0.999）与高储备缓冲是否使换灯后迁移的价值过弱，需独立低储备/共同初态探针，而不是在本轮调学习率。
- C3 Oracle 能取得补给，说明身体与地图在脚本权限下可达；这不证明神经网络会走同一条路。
- C4 反射在 20000 ticks 内存活且光合与 C0 同量级；终点可以落在绘图光区矩形之外（扩散补给）。正式 64 维 Q 足以支持一种局部觅食，不能把 C5 死亡写成“感官没有光信息”。

## 学习链审计（代码，非调参）

1. 方向：`DIRS = [0, π/2, π, −π/2]` → 前/左/后/右；Q 索引 3/7/11/15。`turn=+1` 增加 θ（逆时针），左转后原左侧成为前侧。
2. 64 维数值+有效位进入 `recurrent_features`；缺失填 0、有效位 0/1。
3. `phi = [1, h/√32]`，不是除以 √33。
4. 策略意图在 `SampledIntent`；付费后 `u_effective/w_effective`；实际位移/extent 在几何与反应。覆盖控制器时 `freeze_learning=true`，梯度仍对应抽样意图。
5. 区间在下一次 `decide` 用真实 `interval_d` / `gamma` / `trace_decay` 更新一次。
6. `V_next` 使用更新前的 `v` 与新 `phi`。
7. logits 12–15 置 `-inf`；B 版社交四通道不可执行。
8. actor_lr / critic_lr / entropy_coef / baseline_coef 只出现在 `apply_readout_update` 的规定位置。
9. A0 约束是对读出 `A` 的偏移惩罚，不改基因、不覆盖 `h`。
10. 冻结组只跳过读出更新；维持、感知、代谢、真实控制限制仍在。
